# Converter

У вас есть прога, которая читает CSV и выводит в терминал. На первом файле все ок, на втором фейл. Разобраться в причинах и зафиксить 
```sh
make converter
./converter examples/sample_a.txt
./converter examples/sample_b.txt
```

Патчить исходный код при дебаге нельзя, никаких дебажных принтов.
